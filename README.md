# NEXUS AiEYE

### AI-Powered Real-Time Geospatial Intelligence Interface

**NEXUS AiEYE** is an interactive geospatial visualization platform designed to bring real-time geographic data, live signals, environmental information, aircraft tracking, space missions, CCTV context, and intelligent map overlays into a single immersive interface.

> **NO PLACE LEFT BEHIND.**

---

## 🚀 Features

### 🌍 Interactive 3D Globe

* Photorealistic 3D Earth visualization
* Interactive camera controls
* Location search
* Multiple map visualization styles
* Globe reset and navigation controls

### 📡 Live Data Layers

NEXUS AiEYE can visualize multiple categories of publicly available data, including:

* ✈️ Aircraft
* 🚢 Vessels
* 🌋 Earthquakes
* 🔥 Active fires
* 🛰️ Space missions
* 📍 Geographic locations
* 🏢 Mapped sites and installations
* 📹 CCTV coverage where supported

### 👁️ Intelligence HUD

A customizable heads-up display provides:

* Location information
* Coordinates
* Data-layer status
* Detection overlays
* Environmental information
* Real-time system status

### ✈️ First-Person Cockpit

NEXUS AiEYE includes an immersive aircraft-style cockpit interface featuring:

* Ground speed
* Altitude
* Heading
* Compass
* Pitch and roll indicators
* Route information
* Nearby contacts
* Live signal information

### 🎨 Visual Presets

Choose between different visualization styles:

* NORMAL
* CRT
* NVG
* FLIR
* ANIME
* NOIR
* SNOW

### 📺 CCTV Context

Where supported, the platform can display:

* Camera feeds
* Camera locations
* Coverage information
* Camera selection
* Camera calibration controls
* Scene summaries

### 🎬 Scene System

Create and manage custom visualization scenes:

* Capture shots
* Update shots
* Start/stop scenes
* Navigate between shots
* Export presets
* Import presets
* Run logs

### 📻 Radio

The interface also includes an optional internet-radio companion supporting:

* Station discovery
* Station filtering
* Playback controls
* Volume control
* Station information

---

## 🧠 NEXUS Philosophy

NEXUS AiEYE is built around a simple idea:

**Bring multiple sources of geographic information together into one visual command interface.**

Instead of switching between different maps, dashboards and data sources, NEXUS provides a unified environment for exploring the world.

## 💻 Installation

### 1. Clone the repository

```bash
git clone https://github.com/zeesankhan/nexus-AiEYE.git
```

### 2. Enter the project

```bash
cd nexus-AiEYE
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local address shown by Vite in your browser.

## ⚠️ Important Notice

NEXUS AiEYE is a **visualization and research project**.

The application should not be interpreted as a complete or authoritative representation of the real world.

Live information can be:

* Delayed
* Incomplete
* Inaccurate
* Temporarily unavailable
* Dependent on third-party services

The presence or absence of an object or signal in NEXUS does **not** establish that something does or does not exist.
